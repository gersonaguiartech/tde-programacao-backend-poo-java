# 1º TDE - Programação Backend

Atividade desenvolvida para a disciplina de **Programação Backend** do curso de **Sistemas de Informação** do Centro Universitário Santa Terezinha - CEST.

## 📚 Objetivo

Aplicar os conceitos iniciais de Programação Orientada a Objetos (POO) utilizando a linguagem Java.

## 💻 Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Atributos privados
- Construtores
- Operador `this`
- Getters e setters
- Métodos
- Validação de dados
- Regras de negócio
- Composição de objetos
- ArrayList

## 📂 Exercícios

1. Conta Bancária
2. Retângulo
3. Veículo
4. Data
5. Tempo
6. Estacionamento
7. Nota Fiscal
8. Gestão de Alunos
9. Reservas de Quarto de Hotel
10. Gerenciamento de Funcionários

## 🛠️ Tecnologias

- Java
- Programação Orientada a Objetos (POO)

## 🎓 Disciplina

**Programação Backend — 4º período**
